# ADR-0005: Mac App Store 公開を見据えた設計・実装方針

## ステータス
承認 (Accepted)

## コンテキスト
KetchUp Desktop は、将来的に Mac App Store (MAS) への公開を前提としています。
Apple の審査ガイドラインおよび App Sandbox の制約を初期設計段階から組み込んでおかないと、リリース直前に大規模な手戻りが発生します。

## 主な App Store 審査要件と対応方針

1. **Guideline 5.1.1(v) - アカウントの削除**
   - **要件**: アカウント作成をサポートするすべてのアプリは、アプリ内からアカウントの削除を開始できるようにしなければならない。削除はデータと関連レコードをすべて消去するものでなければならない。
   - **対応**: `/v1/me` (DELETE) API を定義し、設定画面からワンクリックでアカウントおよび紐づく全データ（タスク、ポモ、日報、音声ノート、グループ所属）を物理削除する機能を実装。

2. **App Sandbox 要件**
   - **要件**: Mac App Store のアプリは App Sandbox の有効化が必須。
   - **対応**: `tauri.conf.json` および `Entitlements.plist` で必要最小限の権限（`com.apple.security.network.client`、マイク権限 `com.apple.security.device.audio-input`）のみを宣言し、不要なファイルシステムアクセス権限は要求しない。

3. **マイク利用のパーミッションと説明責任 (Info.plist)**
   - **要件**: 音声日報機能でマイクを使用する際、ユーザーに明確な使用目的を提示する必要がある。
   - **対応**: `NSMicrophoneUsageDescription` に「音声日報の文字起こしを作成するためにマイクを使用します」と明記。

4. **プライバシーポリシーと利用規約**
   - **要件**: 個人情報（Googleアカウント情報、日報、音声データ）を取り扱うため、アプリ内およびストアページにアクセス可能なプライバシーポリシーが必要。
   - **対応**: アプリ内（`/about` / 設定画面）にプライバシー方針を明記。

5. **バンドル識別子 (Bundle ID)**
   - **決定**: `io.github.ryo09020.ketchup` を採用。
