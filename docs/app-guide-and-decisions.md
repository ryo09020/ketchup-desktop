## 1. アプリ概要 & コアコンセプト

従来のポモドーロアプリやタスク管理ツールには、いくつかの根深い「使いにくさ」がありました：
- **時間の誤差**: 25分でタイマーをかけても、10分でタスクが終わって切り上げた場合、多くのアプリでは「25分やったこと」に丸められてしまい、正確な稼働ログが残らない。
- **タームの硬直化**: 人によって集中できる時間は「15分」「45分」「50分」「90分」など異なるのに、変更の手間が大きい。
- **タスク分類の手間**: 大カテゴリ（英語学習、数学、開発など）や小トピック（単語暗記、演習、デバッグなど）をいちいち人間がタグ付け・整理するのが面倒。
- **日報の二重入力**: 「今日やったこと」を既にタスク完了させているのに、日報を書くときに人間がもう一度思い出してタイピングしなければならない。

**KetchUp Desktop は、これらを完全に解決します。**
「機械・AIにできること（時間の計測、タスクの分類、実績の箇条書き）」はすべてアプリが自動で引き受け、**人間は「集中すること」と「そこから得た学び・気づき・内省」にだけ100%フォーカスできる環境** を提供します。

### 1. 秒単位の厳密な実稼働時間トラッキング & 自由ダイヤル式ターム設定

#### ① 秒単位の厳密なトラッキング & 停止ボタン（早送り不要）
- **仕様**: タイマー作動中、バックグラウンドで開始ミリ秒と経過秒数をリアルタイム追跡。タイマー中の早送りボタン（スキップ）は排除し、実稼働を正確に記録する **「停止ボタン」** を配置。
- **実時間によるセッション終了**:
  - タイマーを途中で停止した場合（または「タスク完了して休憩へ」を押した場合）、実際に作業した時間だけを分単位で確定（**59秒以下は0分として換算・切り捨て**）。
  - 例: 10分45秒で停止した場合は「10分作業」として確定・記録。
  - セッション中に作業した分数に基づき、その場で正しいpomoが発行されて記録されます。

#### ② 「25分で1pomo、26分等は繰り上げ」の厳密なpomo計算ルール
- **設計思想**: 集中時間を毎回実際にやった時間（分単位）で更新し、それを25で割って**あまりは繰り上げる**（ceil換算）。
- **計算式**:
  - `稼働分数 = Math.floor(総作業秒数 / 60)` （59秒以下は0分換算）
  - `pomo数 = 稼働分数 === 0 ? 0 : Math.ceil(稼働分数 / 25)`
  - **具体例**:
    - 0分 (0〜59秒): 0 pomo
    - 1分〜25分: **1 pomo**
    - 26分: **2 pomo**（26分のときは切り上げで2pomo！）
    - 50分: **2 pomo**
    - 51分: **3 pomo**
- **DB設計の刷新**:
  - 従来のアプリのように「セッション完了レコード数＝pomo数」とカウントしてしまうと、1分で1レコード作った人と25分集中した人の公平性が崩れてしまいます。
  - そのため、DBテーブル `pomos` に `pomo_count`（25分基準の繰り上げ計算値）を保持し、集計時も `(総集中分数 + 24) / 25` により、常に「25分を1pomoとする」概念を崩さずに正確にアプリへ表示します。

#### ③ タイマー終了音の短音化（~1.4s） & チャイム即時停止ボタン
- **心地よく短いWeb Audioチャイム**: 長すぎた外部音源（20秒の学校のチャイム）を刷新し、澄んだ二音（E5→A5、約1.4秒）のモダンなデスクトップ通知チャイムを内蔵。
- **即時消音ボタン**: チャイム発声中は画面上部に「🔔 音を止める」ボタンが表示され、クリック一つで即座に消音可能。他のコントロールのクリックでも自動で止まります。

#### ④ 自由なダイヤル式ターム設定 & 自動保持
- **UI**: 10分 / 15分 / 25分 / 45分 / 50分 / 60分 のクイックボタン ＋ 1〜180分の自由数値入力。
- **自動記憶**: 一度「50分」にセットすれば、次回起動時や次回セッションも自動で50分からスタート。毎回再設定するストレスがありません。

#### ⑤ タスク未選択時の必須選択ポップアップ ＆ セッション間タスク引き継ぎUX
- **タスク未選択での集中開始防止**:
  - タイマーをタスク未選択の状態でスタートしようとした場合、タイマーは始まらず自動的に **「🎯 集中するタスクを選択」ポップアップ** が表示されます。
  - ポップアップでは「未完了タスク一覧からワンクリックで選ぶ」か「新しいタスクを入力して即座に集中開始」の2通りから直感的に選べます。
- **連続作業時のタスク引き継ぎ（再選択ストレスの解消）**:
  - 一度タスクを選択して集中を始めたら、セッション終了（25分等の満了）や一時停止・停止を行っても、アプリが動いている間は**前回のタスクがそのまま選択状態として保持**されます。
  - 続けて同じタスクに取り組む場合は、再選択の手間なく「再生（開始）」ボタンを押すだけでスムーズに次のセッションに入れます。
- **アプリ起動時（コールドスタート）**:
  - アプリ起動直後はタスク未選択状態（`null`）で立ち上がります（過去履歴を無闇に復元することなく、その時集中したいタスクをフレッシュに選べます）。
- **タスク完了時の自動クリア**:
  - 「タスクを完了して休憩」ボタンでタスクを終了した場合は、タスクの選択が自動でクリアされるため、次回セッション開始時には新しいタスクを選択・作成するポップアップが気持ちよく立ち上がります。

#### ⑥ 本日の24時間 勉強タイムライン（タスク上の横向きバー ＆ 勉強時間帯の可視化）
- **タスク一覧上部へのスマート配置**:
  - タスク管理エリア（[TaskList](file:///Users/ryoota/Documents/ketchup-desktop/apps/desktop/src/components/TaskList/index.tsx)）の真上に、今日1日（0:00〜24:00）の勉強時間を可視化する横向きタイムラインバー [DailyTimelineBar](file:///Users/ryoota/Documents/ketchup-desktop/apps/desktop/src/components/DailyTimelineBar/index.tsx) を配置。
  - 右側の広いカラム幅を活かし、24時間の時間軸が広々と見やすくなっています。
- **統一された美しい勉強時間帯の可視化**:
  - 時間帯ごとのバラつきを抑え、アプリのシグネチャーカラー（トマトレッド／コーラル発光）で統一。
  - 「今日はどの時間帯に集中して勉強したのか」がひと目で直感的にわかるUIを提供。
- **現在時刻マーカー（NOW） ＆ リアルタイム集中パルス**:
  - バー上には常に「現在の時刻」を示すホワイトのニードルが正確に刻まれます。
  - タイマー作動中は、現在進行中のセッションがリアルタイムで発光パルスアニメーションしながらバー上に伸びていきます。
- **インタラクティブな詳細ツールチップ**:
  - 勉強したブロックにマウスを合わせると、浮動カードで「開始〜終了時刻（例: 14:20〜14:45）」「実作業分数・pomo数」「取り組んだタスク名」「カテゴリ」が美しく表示されます。

### 2. 🗺️ AIトピッククラスタリング & Obsidian Map風ビュー

#### ① タスク内容からAIが自動分類
- **仕組み**: ユーザーがタスク名（例: `ターゲット1900 1〜100暗記` や `線形代数 固有値問題の演習`）を入力すると、Google Gemini API（または内蔵ヒューリスティック分類エンジン）が自動判定：
  - **大グループ（Category）**: `英語学習`, `数学`, `開発・プログラミング`, `業務・デスクワーク`, `研究・論文`, etc.
  - **小グループ（Topic）**: `英単語暗記`, `過去問・問題演習`, `実装・コーディング`, `仕様策定`, etc.
- **人間のガイドラベル入力**: フォーム内に「💡 大ラベル指定（任意）」を用意。人間が「英語学習」と入れておけば、AIはその大枠を尊重しながら最適な小トピックを自動生成します。

#### ② 画面ごとの明確な役割分担 ＆ Obsidian風 多角的ネットワークマップ
- **タイマー画面（TimerPage: 集中特化・超シンプル）**:
  - タイマー画面では余計なラベルや過剰な装飾を完全に排除。
  - **[未完了タスク一覧]** ([SimpleTaskList](file:///Users/ryoota/Documents/ketchup-desktop/apps/desktop/src/components/SimpleTaskList/index.tsx)) を配置し、「チェック」「タスク名」「即座に始められる [集中] ボタン」「削除」だけに研ぎ澄ませた、ノイズゼロのUIを提供。
- **タスク画面（TaskPage: 思考・整理・鳥瞰）**:
  - ここに **Obsidian風 ネットワークマップ（SVG Graph）** ([TaskList](file:///Users/ryoota/Documents/ketchup-desktop/apps/desktop/src/components/TaskList/index.tsx)) を本格搭載。
  - **多角的な文脈の繋がり（曖昧さの解決）**:
    - 「留学のための英語」「次の模試のための英語」のように、タスクは1つのフォルダに収まらない曖昧さを持ちます。
    - 各タスクは `#英語` `#留学` `#模試` のように複数の文脈ハブと**網の目（線）で同時に繋がってクラスタを形成**。
    - ノードにマウスを重ねると関連するハブやタスクが強調され、自分の活動の多面的な繋がりが一目で把握できます。
- **デザインシステム（発光エフェクトの廃止とミニマリズム）**:
  - ネオンのような派手な発光（glow）を排除し、NotionやLinearのように**端正な線と余白、高いコントラストで構成された「シンプルで見やすい」ミニマルUI**に統一。

### 3. 📝 AI事実自動集計 ＆ 人間の「学び・気づき」特化型日報

#### ① 実績の自動集計（Factsの自動生成）
- 日報画面を開くか「実績から自動下書き」を押すと、今日完了したタスク、各カテゴリごとの実作業分数、合計集中時間、pomo換算数をAIが自動集計して下書きを構成：
  ```markdown
  ## 📊 本日の活動実績 (AI自動生成)
  - 英語学習 (英単語暗記): ターゲット1900 1〜100暗記 (45分 / 1.8 pomo)
  - 数学 (問題演習): 線形代数 固有値問題 (50分 / 2.0 pomo)
  - **本日総集中時間**: 95分 (3.8 pomo)
  ```
- **人間が「今日何をやったか」を思い出しながら手入力する必要は一切ありません。**

#### ② 人間は「学び」「課題」にだけフォーカス
- 画面上部に以下の専用インプットを配置：
  - 💡 **今日の学び・気づき (Learnings)**: 今日新しく知った知識、発見、ひらめき
  - 🚧 **課題・反省点 (Challenges)**: つまずいた点、集中が途切れた原因
  - 🚀 **明日のネクストアクション (Next Actions)**: 明日最初に着手するタスク
- 入力内容は即座にマークダウン本文の該当見出しへ反映され、右側タブのプレビューで確認できます。

### 4. 💎 Obsidian Vault ローカルファイル直結連携

#### ① プラグイン不要・ダイレクトファイル保存
- 設定画面で `~/Documents/ObsidianVault/DailyNotes` などの Obsidian Vault パスを指定しておくだけ。
- 日報エディタの **「Obsidian に保存 💎」** を押すと、Tauri のネイティブ Rust バックエンドがローカルファイルシステムに直接アクセスし、`2026-10-24.md` を書き込みます。

#### ② Obsidian 準拠の YAML Frontmatter 構造
出力される Markdown は、Obsidian の Dataview やタグ検索に完全対応：
```markdown
---
date: 2026-10-24
type: daily-report
focus_minutes: 95
pomo_count: 3.8
score: 85
tags:
  - daily-report
  - ketchup
---

## 📊 本日の活動実績 (AI自動生成)
- 英語学習 (英単語暗記): 45分
- 数学 (問題演習): 50分

## 💡 本日の学び・気づき
(ユーザーが入力した知見)

## 🚧 課題・反省点
(ユーザーが入力した改善点)

## 🚀 明日のネクストアクション
- [ ] ターゲット1900 101〜200
```
- Obsidian を開けば、何の設定も追加プラグインも不要で、そのまま今日のノートとして閲覧・グラフリンク可能。
- デスクトップアプリ外（ブラウザ環境など）で動かす場合も、自動的に同名 Markdown ファイルとしてローカルダウンロードされるフォールバックを完備。

## 3. 技術スタックと選定理由（なぜこれを選択したのか）

| 領域 | 選定技術 | 選定理由・メリット |
| :--- | :--- | :--- |
| **デスクトップ基盤** | **Tauri v2 + Rust** | 起動速度 <0.3秒、メモリ消費 15MB〜30MB（Electronの約1/10）、Mac App Store サンドボックス完全準拠、ローカルファイル直結書き込み |
| **バックエンド API** | **Go (chi + pgx)** | シングルバイナリ、高速起動、超低レイテンシ、型安全性、メモリ消費 10MB 未満 |
| **データベース & 認証** | **Supabase (PostgreSQL + Auth)** | Row Level Security (RLS) による堅牢なマルチテナント分離、Google SSO 連携、REST/Realtime サポート |
| **オフライン / ローカル** | **Local-First Engine** | サーバー未起動やオフラインでも 100% 動作。`localStorage` と双方向フォールバック |
| **AI プロバイダー** | **Google Gemini API** | 音声文字起こし（音声日報）とタスク分類・日報まとめを同一モデル（Flash 1.5/2.0）で超高速・安価に実現 |
| **フロントエンド** | **React 19 + TypeScript + Vite + SCSS** | 型安全、高速HMR、Tailwindのバージョン依存やクラス肥大化を排した柔軟で美しいCSS変数ベースのUI |

---

### Tauri v2 + Rust を選んだ理由（vs Electron）
- **メモリ・リソースの圧倒的な軽さ**: Electron アプリ（Slack, Notion, Discord 等）は内部で Chromium と Node.js を丸ごと起動するため、起動するだけで 200MB〜400MB のメモリを消費します。作業中に常時起動しておくポモドーロタイマーとしては不適格です。
- Tauri v2 は macOS 標準の WebKit (WKWebView) を利用するため、バイナリサイズわずか 30MB、メモリ消費は約 20MB に抑えられます。
- **App Store サンドボックスへの適応**: macOS App Store のガイドライン（Sandboxing, Hardened Runtime）に標準で準拠しており、App Store 申請でリジェクトされるリスクを最小化しています。
- **ネイティブファイル I/O**: Obsidian Vault への保存など、OS のファイルシステムへ安全・高速にアクセスできます。

### Go (chi + pgx) を選んだ理由（vs Node.js / Python）
- Go の静的バイナリは依存関係がなく、クラウド（Fly.io / Render）にもローカルデーモンとしても即座に起動できます。
- ポモドーロタイマーのセッション同期や WebSocket / SSE 通信において、Go の Goroutine は数万接続を最小限のリソースで捌くことが可能です。
- エラーハンドリングが明示的で、App Store ガイドライン 5.1.1(v) に定められた「ユーザーアカウントおよび全データの物理削除（DELETE /v1/me）」のような安全性が極めて重要なエンドポイントを、トランザクション安全に確実に実装できます。

### Local-First（ローカルファースト）設計を採用した理由
- タイマーアプリや日報ツールで一番ストレスなのは、「通信環境が悪いとタイマーが止まる」「オフラインだとタスクが保存できない」という事態です。
- KetchUp Desktop は **「ローカルが常に正」** の Local-First アーキテクチャを採用。
  - バックエンドサーバーが起動していなくても、ローカルの `localStorage` ＋ 内蔵分類アルゴリズムによって全機能がオフラインで完全に動作します。
  - サーバー接続時は自動的にクラウド（PostgreSQL）と同期します。

### Google Gemini API を選んだ理由（vs OpenAI）
- **マルチモーダル単一パイプライン**: 音声日報の録音データ（WebM/MP3）をそのまま送信し、文字起こし＋構造化要約を1ステップで実行可能（Whisper ＋ GPT-4 のように2回APIを叩くコストとレイテンシを半減）。
- **長文コンテキスト & コストパフォーマンス**: Gemini 1.5/2.0 Flash は爆速かつ非常に安価なため、日常のタスク分類や日報要約を気兼ねなく自動実行できます。

### デザインシステム（Vanilla SCSS + CSS 変数）
- KetchUp のデザインは、Ketchup Red (`#e53935`) と Soft Break Green (`#10b981`)、Obsidian Purple (`#7c3aed`) をアクセントにした洗練されたミニマリズム。
- CSS カスタムプロパティ（CSS Variables）により、ライトモード・ダークモードの切り替えが瞬時に行え、OS のテーマ変更にも滑らかに追従します。

## 4. 既存アプリとの比較（どう何がいいのか）

| 比較項目 | 一般的なポモドーロアプリ (Focus ToDo 等) | 汎用ノート / 日報ツール (Notion / Obsidian) | **KetchUp Desktop 🍅** |
| :--- | :--- | :--- | :--- |
| **途中終了の記録** | 25分に丸められる（誤差大） | 手動で記録する必要あり | **秒単位で実時間のみ記録（正確）** |
| **タームの柔軟性** | 25分固定が多い / 変更が面倒 | タイマー機能なし | **ダイヤル式で自由に設定・自動記憶** |
| **1 pomo の定義** | ターム回数（時間の長さがバラバラ） | なし | **「累計25分＝1pomo」で完全統一** |
| **タスク分類** | 人間が手動でフォルダ分け・タグ付け | 人間がプロパティ入力 | **AIがタスク名から大・小グループを自動クラスタリング** |
| **タスク可視化** | 単純な縦並びリスト | データベースビュー | **Obsidian Map風 AIトピッククラスタ表示** |
| **日報の作成** | なし（別アプリが必要） | 人間が一から手動入力 | **本日の実績はAIが自動集計。人間は「学び」だけに特化** |
| **Obsidian 連携** | なし（コピペが必要） | 本家アプリ | **ワンクリックで Vault の Daily Notes へ直結保存** |
| **デスクトップ常駐** | ウィンドウが大きく邪魔になりがち | ウィンドウが重い | **メニューバー表示 ＋ 最前面フローティングミニタイマー** |
| **メモリ消費** | 150MB〜300MB (Electron) | 300MB〜500MB (Electron) | **15MB〜30MB (Tauri v2 + Rust)** |

## 5. まとめ

KetchUp Desktop は、単なる「時計が減っていくだけのタイマー」でも「単なるToDoリスト」でもありません。

**「日々の集中時間を1秒の狂いもなく自分の資産として可視化し、タスクの整理や日報の二重入力という無駄な作業をAIが肩代わりし、蓄積された知見が自分の第2の脳（Obsidian）へシームレスに同期されていく」**

ユーザーが本来持つ創造性や学習効率を最大化するための、最も洗練された集中ハブです。
